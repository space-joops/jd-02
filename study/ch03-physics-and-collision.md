# Chapter 3: 물리 엔진과 충돌 판정 (Physics & Collision)

우주를 부유하는 펫을 조종할 때 멈추고 싶다고 바로 멈추지 않고 미끄러지죠? 이 '관성'을 구현하려면 간단한 고등학교 물리 지식이 필요합니다.

## 1. 위치, 속도, 가속도
게임 속 모든 물체는 세 가지 상태를 가집니다.
- **위치 (`x`, `y`)**: 현재 물체가 어디에 있는가?
- **속도 (`vx`, `vy`)**: 물체가 얼마나 빠르게 이동 중인가?
- **가속도**: 물체의 속도를 얼마나 빠르게 변화시킬 것인가? (조이스틱 입력)

우리의 조이스틱(방향키)을 누르면 물체의 위치가 아니라 **"속도"**가 증가합니다.
```tsx
// 조이스틱을 오른쪽으로 당기면 (dx > 0)
const THRUST = 800; // 가속도 (엔진 파워)
vx += dx * THRUST * dt; 

// 속도만큼 위치 이동
x += vx * dt;
```
이렇게 하면 우주선의 엔진처럼 서서히 가속하고 방향을 바꾸는 묵직한 조작감이 완성됩니다.

## 2. 마찰력 (Friction)
우주공간이라도 조이스틱을 놨을 때 영원히 날아가면 게임이 너무 어렵습니다. 매 프레임마다 속도를 조금씩 줄여주는 마찰력을 곱해줍니다.
```tsx
const FRICTION = 0.98; // 1보다 작은 값을 계속 곱하면 0에 수렴합니다.
vx *= Math.pow(FRICTION, dt * 60);
vy *= Math.pow(FRICTION, dt * 60);
```
이렇게 하면 조이스틱을 놓는 순간부터 스르륵 미끄러지면서 멈추게 됩니다.

## 3. 원형 충돌 판정 (Circle Collision)
우리의 펫과 우주 쓰레기, 가시 장애물은 모두 완벽한 사각형이 아니라 둥근 형태에 가깝습니다. 그렇다면 두 동그라미가 부딪혔는지는 어떻게 알 수 있을까요? 바로 **피타고라스의 정리**입니다!

두 물체의 중심점 사이의 거리(대각선)가, 두 물체의 반지름(r)을 더한 값보다 짧아지면 두 물체는 서로 겹친(충돌한) 상태입니다.

```tsx
// A물체(주인공)와 B물체(가시)의 충돌 검사
function isColliding(a, b) {
  const dx = a.x - b.x; // 가로 길이
  const dy = a.y - b.y; // 세로 길이
  
  // 두 점 사이의 거리 (a^2 + b^2 = c^2)
  const distance = Math.sqrt(dx * dx + dy * dy); 
  
  // 중심 간의 거리가 두 반지름의 합보다 작으면 충돌!
  return distance < (a.r + b.r);
}
```
"SPACE JOOPS"에서는 매 프레임마다 내 캐릭터와 화면상의 수십 개의 쓰레기/가시 간의 `isColliding`을 계산하여 충돌 시 이벤트를 발생시킵니다. 

## 4. 자석 효과 (Magnet)
업그레이드 중 "자석" 기능은 어떻게 작동할까요? 이것도 거리 계산의 응용입니다!
거리를 측정해서 자석 범위(`MAGNET_RANGE`) 안에 쓰레기가 들어오면, 쓰레기의 이동 속도(`vx, vy`)를 주인공이 있는 방향으로 강제로 틀어버립니다.

```tsx
if (distance < MAGNET_RANGE) {
  // 쓰레기가 주인공 쪽으로 끌려오는 벡터를 계산하여 속도에 더해줌
  const pullStrength = 500;
  junk.vx += (dx / distance) * pullStrength * dt;
  junk.vy += (dy / distance) * pullStrength * dt;
}
```
