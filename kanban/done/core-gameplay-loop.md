# 🚀 Core Gameplay Loop (MVP)

## 🎯 Design Vision
The goal is to create a frictionless, hyper-casual survival experience that instantly hooks the player. The "one-finger" gameplay ensures maximum accessibility for mobile users.

## ✅ Completed Features
- **Virtual Joystick Physics**: Implemented a smooth, inertia-based movement system. The pet glides through space, consuming thrust gas, simulating zero-gravity friction.
- **Dynamic Difficulty**: Spawns (satellites, bolts, cans, springs) and hazards (red spikes) scale dynamically based on the player's score.
- **Growth System**: The pet visually scales up as it consumes junk, satisfying the primal "growth/evolution" loop of idle games.
- **Hit & Invincibility**: Added screen shake, a 1.4-second invincibility frame, and blinking effects to ensure the player feels the impact without being instantly punished.

## 🧠 Designer's Note
The core loop is solid. The friction and acceleration values in `TUNE` have been perfectly balanced to make movement feel "weighty" yet responsive.
