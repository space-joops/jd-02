# 🪐 Meta-Progression & Backend System (Brainstorming)

## 1. 알단계(Egg) 분양 및 고유 펫 네이밍
**기획 의도**: 플레이어에게 강렬한 소속감과 애착을 부여하기 위한 첫 번째 단계.
- **메커니즘**: 처음 게임에 접속하면 화면 중앙에 떠 있는 '우주 알'을 터치하여 부화시킵니다.
- **네이밍 규칙**: 오직 영어 알파벳과 숫자만 허용 (글로벌 랭킹 가독성 확보). 중복 불가능 (Unique Name).
- **기술 스택**: Vercel API Route에서 닉네임 중복 여부를 빠르게 검증하고, Supabase의 `players` 테이블에 고유키(Unique Key)로 저장합니다.

## 2. 듀얼 리더보드 (Dual Leaderboard) & 랭크 시스템
**기획 의도**: '피지컬이 좋은 유저(단판)'와 '꾸준히 하는 유저(누적)' 모두에게 보상을 주고, 승급/강등 알림으로 강력한 리텐션(재방문)을 유도합니다.
- **단판 점수(High Score) 리더보드**: 순수하게 오랫동안 살아남아 많은 점수를 낸 아케이드 랭킹.
- **누적 총점(Cumulative) 리더보드**: 지금까지 치운 우주 쓰레기의 총합. 노력의 결정체.
- **승급/강등 연출**: 게임 메인 화면에 들어올 때 "▲ 축하합니다! 상위 10% (Silver 랭크)로 승급했습니다!" 혹은 "▼ 누군가 당신을 추월했습니다. 현재 랭킹 412위" 같은 팝업을 띄워 경쟁심을 자극합니다.

## 3. 우주쓰레기 히스토리 및 인벤토리 (Junk Inventory)
**기획 의도**: 단순히 숫자가 오르는 것을 넘어, 내가 '무엇을' 수집했는지 시각적으로 보여주어 수집욕을 자극합니다.
- **히스토리/도감**: 지금까지 먹은 인공위성, 캔, 볼트 등의 종류와 개수를 기록하는 도감 화면.
- **인벤토리(아이템함)**: 획득한 쓰레기들이 보관되는 창고.

## 4. 진화(Evolution) 및 연구(Upgrade) 시스템
**기획 의도**: 수집한 쓰레기를 소모하여 펫을 더 멋지게 키우고, 능력을 강화하는 RPG 요소 결합.
- **능력치 연구 (기존 UPG 대체)**: "캔 100개 + 볼트 50개 = 추진기(Thruster) 레벨업" 처럼 특정 쓰레기 조합을 요구하여 목표 부여.
- **진화 (Evolution)**: 누적 총점이나 특정 희귀 쓰레기(예: 황금 인공위성)를 먹었을 때 펫의 외형이 변함 (예: 알 -> 꼬마 펫 -> 뿔 달린 펫 -> 사이보그 펫). 진화 시 패시브 능력(당김력 증가 등) 추가 부여.
